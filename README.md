# Stroke_Prediction_using_ML
🧠 Stroke Prediction Using Exploratory Data Analysis (EDA) 📊
🚀 Just completed a detailed EDA on a healthcare dataset related to stroke prediction using Python and visualization libraries like Pandas, Seaborn, and Matplotlib.
🔍 In this project, I analyzed key health-related features such as:
Age
Hypertension
Heart Disease
Smoking Status
BMI and more
📈 The analysis helped uncover:
Class imbalance between stroke and non-stroke cases
Trends in categorical features like work type, gender, and residence
Potential risk factors contributing to strokes
📂 Dataset Source: IEEE DataPort – Stroke Prediction Dataset
💡 This kind of EDA is crucial before applying machine learning models, as it guides preprocessing decisions and helps build more accurate and meaningful models.
